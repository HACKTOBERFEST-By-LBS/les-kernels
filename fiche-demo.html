Comment ça juge (à dire si on demande)

  • Gemma lit le message avec 13 exemples annotés sous les yeux.
  • Des règles fixes repassent derrière : code, PIN, « renvoyez », frais, lien, code *…# vers un numéro, faux proche, message « officiel » venu d'un numéro. Elles peuvent durcir le verdict, jamais l'adoucir.
  • Mémoire collective : un message proche d'arnaques déjà signalées ne peut plus être « normal » à partir de 2 personnes.
  • Le premier mot (ARNAQUE, DOUTEUX, NORMAL) est écrit par notre code, pas par l'IA.
  • Au-delà des opérateurs : banques, colis, emploi, prêts, faux proches.

Sans code, tout message est analysé. Le volet cours ne s'ouvre qu'avec une commande.

Les 5 réflexes

  1. Personne de T-Money, Moov ou de la banque ne demande un code ou un PIN.
  2. Un dépôt « par erreur » ne se renvoie pas : on vérifie son vrai solde.
  3. Les vrais avis viennent d'un nom (TMONEY, MOOV, la banque), pas d'un numéro.
  4. Aucun frais pour un gain, un colis, un emploi ou un prêt.
  5. Devant l'urgence : attendre et appeler quelqu'un de confiance.

Si quelque chose coince

« Je n'ai pas pu lire ce message » : l'API Google a un raté passager. Relancer une fois. Une arnaque évidente est quand même signalée par les règles (« analyse partielle »).

WhatsApp ne répond pas : continuer sur le site, il fait exactement la même analyse. Ne pas perdre de temps à relancer le relais.

Le mur est vide : onglet Numéros, bouton « Afficher l'exemple du jury ».

À ne pas dire

  • Le bot ne voit pas le vrai solde : c'est pour ça qu'il dit de le vérifier.
  • Tous les numéros montrés sont fictifs (+228 00 00 00 xx).
  • Ne pas ouvrir la page admin ni montrer le fichier .env.
